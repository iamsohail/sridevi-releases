## APK contents

Every APK carries the Firebase Android API key from `google-services.json` (`resources.arsc`). That key is public by design in every Android app; its protection is its restrictions in Google Cloud (an application restriction to the app's package and signing certificate, and an API restriction to the Firebase APIs the app uses).

One further compiled-in key was found in some older builds. Its details are reported to the owner privately, not in this public repository. No private keys, service-account JSON, AWS or OpenAI-style keys were found in any APK.
